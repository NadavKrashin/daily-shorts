Why in Clay Publisher: architecture

Private, single-user internal tool. Runs on the channel owner's own computer; not reachable from the internet.

1. Video production

Our own studio workflow produces each finished Short (animation, narration, captions, fact-checked sources) and adds it to a private episode list.

No YouTube API use in this step.

→

2. Why in Clay Publisher (owner's Mac)

  • Imports the finished episode
  • Technical checks (format, audio, length)
  • Schedules one upload (max 1/day)
  • Stores OAuth token + own stats locally (private database)
  • Owner dashboard over a private network (Tailscale)
→

3. YouTube API Services

  • Data API v3: videos.insert (upload own video), videos.list / channels.list (own channel)
  • Analytics API: reports.query (own channel's views, watch time, retention)
  • OAuth 2.0, channel owner only: youtube.upload, youtube.readonly, yt-analytics.readonly

Only the Why In Clay channel is accessed. No other channels, no other users, no data shared or sold. Access can be revoked at any time in the owner's Google Account (Security → Third-party connections).

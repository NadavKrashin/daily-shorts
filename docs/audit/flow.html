Why in Clay Publisher: user flow

The only user is the channel owner.

1Owner signs in onceGoogle OAuth consent screen ("Why In Clay"): upload videos, view own YouTube account, view own YouTube Analytics. Token is stored only on the owner's computer.
2A finished Short is readyThe tool imports it and runs technical checks. The owner can review it in the private dashboard.
3ScheduledThe video gets the next publishing slot (at most one upload per day, about three per week).
4Uploadvideos.insert uploads it to the owner's own channel with title, description, sources and AI-content disclosure.
5Own statisticsFor about 35 days the tool reads the video's views, watch time and retention (videos.list, Analytics reports.query).
6Owner decides next topicsStatistics stay internal and help pick future videos. Access can be revoked at any time in the Google Account.
